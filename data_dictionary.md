# Data Dictionary

## NYC Yellow Taxi Trip Record Data

This project uses NYC Taxi & Limousine Commission Yellow Taxi trip records from January 2025 to July 2025.

### Main Fields

| Column | Description |
|---|---|
| VendorID | Technology provider that provided the record |
| tpep_pickup_datetime | Date and time when the trip started |
| tpep_dropoff_datetime | Date and time when the trip ended |
| passenger_count | Number of passengers |
| trip_distance | Trip distance in miles |
| RatecodeID | Rate code used for the trip |
| PULocationID | Pickup taxi zone |
| DOLocationID | Drop-off taxi zone |
| payment_type | Payment method |
| fare_amount | Base fare |
| extra | Additional charges |
| mta_tax | MTA tax |
| tip_amount | Tip amount |
| tolls_amount | Toll charges |
| improvement_surcharge | Improvement surcharge |
| total_amount | Total amount charged |
| congestion_surcharge | Congestion surcharge |
| airport_fee | Airport fee, where applicable |

## Data Period

January 2025 – July 2025

## Source

NYC Taxi & Limousine Commission (TLC)

Official source:

https://www.nyc.gov/site/tlc/about/tlc-trip-record-data.page
